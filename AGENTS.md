# Project guidance

## Collaboration

The user is an aspiring AI-driven developer learning to build software through prompts and collaboration with an AI coding agent. The user describes desired outcomes and provides feedback; the agent takes ownership of implementation from start to finish. Explain completed work in clear, beginner-friendly language so the user can learn from the results.

## Implementation

This repository is a Frontend Mentor newbie project. Keep solutions simple, readable, responsive, accessible, and appropriate for a beginner.

- Use only HTML, CSS, and vanilla JavaScript. Do not install or introduce libraries, frameworks, packages, build tools, or dependencies.
- Use JavaScript only when genuine interactivity requires it.
- Inspect existing files and the README before editing, and preserve unrelated work.
- Use semantic HTML and modern CSS. Avoid overengineering.
- Verify layout across mobile and desktop sizes, and check accessibility, including keyboard navigation, focus states, image alternatives, and readable contrast.

## Public repository and private files

This is a public repository. Never publish secrets, credentials, tokens, private URLs, personal data, sensitive configuration, private notes, or user-specific comments unsuitable for a random visitor.

Code comments must explain the public project rather than communicate privately with the user. Sensitive values belong in ignored local files or environment variables, with safe placeholders in tracked example files.

The entire `docs/` directory is private local workflow material and excluded from version control. Keep design references and private documentation there.
